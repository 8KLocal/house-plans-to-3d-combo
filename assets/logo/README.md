# 8K by AK maker's mark

Copied unchanged from `/workspace/8k-by-ak-3d-print/` (see `SOURCE_README.txt`).
Used by `hp3d/brand.py`, which recesses the mark into the underside of every
generated floor slab (pipeline and in-app editor rebuilds).

- `8K-by-AK-relief-80mm.stl` - full stacked lockup (electric italic 8K, coral
  divider bar, "by AK"), 80 mm wide, 1.8 mm thick, mm, centered, Z=0..1.8.
- `8K-only-relief-50mm.stl` - 8K only, 50 mm wide; used on small bases where
  "by AK" would be too small to print.
- `*.svg` - vector sources.

Do not regenerate these with a different font: the sharp electric 8 is the brand.
